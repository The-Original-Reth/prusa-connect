### Added
- `GET /api/v1/devices/{device_id}/jobs`, the job history and the fleet's jobs now give each print a `filament_used_mm`, measured by the machine's extruder odometer from the start of the print. It is absent for a print first seen after it began, and for prints stored before this release.
- A print of a file this server sent to the printer now carries `slicer`: the filament, weight, time and material the slicer wrote into the file.
